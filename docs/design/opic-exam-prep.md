# 오픽 준비 고도화 설계 (② 외운 문장 복습 · ① 답변 전체 이어 말하기 · ③ 실전 모의고사)

- 의도: [`docs/intent/opic-exam-prep.md`](../intent/opic-exam-prep.md)
- 화면 시안 (2026-11-21 승인): https://claude.ai/artifact/YAsudxUcgYs2wp6iGKP9mS
- 만드는 순서: ② → ① → ③. 이 문서는 ②를 자세히, ①③은 만들 때 채운다.

## 승인 때 확정한 것

1. 복습에서 못 기억한 문장은 "한 번 더 말해 보기"로 맞혀도 외움 표시가 풀린 채로 둔다. 외움은 외우기 연습(가리고 말하기 90점)에서만 돌아온다.
2. 이어 말하기에서 막힌 문장은 외움 표시를 그대로 두고, 다시 연습할 목록에만 넣는다.
3. 모의고사를 끝내지 않고 나가면(앱을 닫거나 끊겨도) 그 시험은 버리고 횟수를 차감하지 않는다. 이어 보기는 없다.

## ② 외운 문장 복습

### 데이터 (`supabase/migrations/0011_sentence_recall.sql`)

`sentence_progress`에 두 칸을 더한다.

| 칸 | 뜻 |
| --- | --- |
| `recall_step` (0~4) | 지금까지 통과한 복습 수. 4 = 네 번 모두 통과, 복습 끝 |
| `next_recall_on` (date) | 다음 복습일 (한국 날짜). null = 복습 없음 |

- 간격: 통과 수 0 → 1일, 1 → 3일, 2 → 7일, 3 → 14일 (`recall_gap()`, 화면 쪽 `RECALL_GAPS`와 같다).
- **트리거**가 일정을 잡는다. 외움이 되는 순간(연습 → 외움) `recall_step = 0`, `next_recall_on = 내일`. 외움이 풀리면 일정을 지운다. 외운 문장을 다시 연습(외움 → 외움)해도 일정은 그대로. 그래서 기존 연습 화면(`/api/feedback`)은 고치지 않았다.
- **`record_recall(문장, 통과?)`**: 로그인한 본인의, 오늘까지 복습할(외움 + `next_recall_on <= 오늘`) 문장만 바꾼다. 통과면 다음 간격으로(네 번째면 끝), 실패면 `practicing`으로. 조건에 안 맞으면 `not_due`(P0002) 오류.
- 이미 외운 문장(배포 전): 사람마다 하루 15문장씩, 내일부터 나눠서 첫 복습을 잡는다 (한꺼번에 몰리지 않게).
- 테스트: `supabase/tests/06_recall.sql`.

### 채점 · 비용

- `/api/recall`: 서버에서 단어 비교(`compareSentences`)만 한다. AI를 부르지 않고 하루 사용량도 차감하지 않는다.
- 90점(`MEMORIZED_SCORE`) 이상이면 기억함. "모르겠어요"는 0점 · 못 기억함.
- `retry`(한 번 더 말해 보기): 점수만 돌려주고 진도는 바꾸지 않는다 (확정 1).
- 복습 1문장마다 학습 기록(`daily_activity.reviews`)을 올려 연속 학습일에 들어가게 한다.

### 화면

- 홈 (오픽 암기): 오늘 복습할 문장이 있으면 "오늘 할 것" 자리에 **오늘의 복습** 카드가 먼저 나오고, 원래 카드는 그 아래 작은 카드("그다음 · …")로 내려간다.
- 복습할 문장: 지금 쓰는 답변(보관되지 않은 내 스크립트, 지금 등급의 AI 답변)의 것만 (`pickDue`). 오래 밀린 것 먼저.
- `/recall`: 한 번에 최대 20문장 (`RECALL_SESSION`). 남으면 요약 화면에서 "이어서 더 복습".
- 한글 뜻만 보여 주고 영어는 가리며 소리도 들려주지 않는다. 결과는 기억함(다음 복습일) / 못 기억함(빠진 단어 표시, 외움 표시 풀림).
- 요약: 기억한 수, 다시 외울 문장 목록. 누르면 그 문장부터 외우기 연습(`/practice/<주제>?v=<답변>&start=<문장>`).

## ① 답변 전체 이어 말하기 (만들 때 채움)

- 시안: 주제 화면(다 외웠을 때 큰 버튼) → 질문 듣기 · 시작 → 말하는 중(시간, 받아 적기) → 결과(일치도 · 걸린 시간 · 막힌 문장).
- 채점은 단어 비교, AI 비용 없음. 막힌 문장 = 그 문장 일치도 80% 미만 (가정). 3분이 넘으면 자동으로 끝냄 (가정).

## ③ 실전 모의고사 (만들 때 채움)

- 시안: 시작 안내(이달 남은 횟수) → 배경 설문 → 난이도 1~6 → 15문항(질문은 소리로만, 문항마다 다시 듣기 1번, 전체 40분) → 7번 뒤 난이도 다시 고르기 → 리포트 만드는 중 → 예상 등급 → 문항별 피드백. 운영자 회원 화면에 "모의고사 한도(월)".
- 횟수는 15번을 마친 순간 차감. 리포트 만들기가 실패하면 다시 만들 수 있고 추가 차감은 없다.
- 리포트만 Sonnet, 1회 약 100~200원. "예상"과 받아 적은 글자만 본 한계를 화면에 적는다.
