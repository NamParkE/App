# 오픽 준비 고도화 설계 (② 외운 문장 복습 · ① 답변 전체 이어 말하기 · ③ 실전 모의고사)

- 의도: [`docs/intent/opic-exam-prep.md`](../intent/opic-exam-prep.md)
- 화면 시안 (2026-11-21 승인): https://claude.ai/artifact/YAsudxUcgYs2wp6iGKP9mS
- 만드는 순서: ② → ① → ③. 이 문서는 ②를 자세히, ①③은 만들 때 채운다.

## 승인 때 확정한 것

1. 복습에서 못 기억한 문장은 "한 번 더 말해 보기"로 맞혀도 외움 표시가 풀린 채로 둔다. 외움은 외우기 연습(가리고 말하기 90점)에서만 돌아온다.
2. 이어 말하기에서 막힌 문장은 외움 표시를 그대로 두고, 다시 연습할 목록에만 넣는다.
3. 모의고사를 끝내지 않고 나가면(앱을 닫거나 끊겨도) 그 시험은 버리고 횟수를 차감하지 않는다. 이어 보기는 없다.

## ② 외운 문장 복습

### 데이터 (`supabase/migrations/0011_sentence_recall.sql`)

`sentence_progress`에 두 칸을 더한다.

| 칸 | 뜻 |
| --- | --- |
| `recall_step` (0~4) | 지금까지 통과한 복습 수. 4 = 네 번 모두 통과, 복습 끝 |
| `next_recall_on` (date) | 다음 복습일 (한국 날짜). null = 복습 없음 |

- 간격: 통과 수 0 → 1일, 1 → 3일, 2 → 7일, 3 → 14일 (`recall_gap()`, 화면 쪽 `RECALL_GAPS`와 같다).
- **트리거**가 일정을 잡는다. 외움이 되는 순간(연습 → 외움) `recall_step = 0`, `next_recall_on = 내일`. 외움이 풀리면 일정을 지운다. 외운 문장을 다시 연습(외움 → 외움)해도 일정은 그대로. 그래서 기존 연습 화면(`/api/feedback`)은 고치지 않았다.
- **`record_recall(문장, 통과?)`**: 로그인한 본인의, 오늘까지 복습할(외움 + `next_recall_on <= 오늘`) 문장만 바꾼다. 통과면 다음 간격으로(네 번째면 끝), 실패면 `practicing`으로. 조건에 안 맞으면 `not_due`(P0002) 오류.
- 이미 외운 문장(배포 전): 사람마다 하루 15문장씩, 내일부터 나눠서 첫 복습을 잡는다 (한꺼번에 몰리지 않게).
- 테스트: `supabase/tests/06_recall.sql`.

### 채점 · 비용

- `/api/recall`: 서버에서 단어 비교(`compareSentences`)만 한다. AI를 부르지 않고 하루 사용량도 차감하지 않는다.
- 90점(`MEMORIZED_SCORE`) 이상이면 기억함. "모르겠어요"는 0점 · 못 기억함.
- `retry`(한 번 더 말해 보기): 점수만 돌려주고 진도는 바꾸지 않는다 (확정 1).
- 복습 1문장마다 학습 기록(`daily_activity.reviews`)을 올려 연속 학습일에 들어가게 한다.

### 화면

- 홈 (오픽 암기): 오늘 복습할 문장이 있으면 "오늘 할 것" 자리에 **오늘의 복습** 카드가 먼저 나오고, 원래 카드는 그 아래 작은 카드("그다음 · …")로 내려간다.
- 복습할 문장: 지금 쓰는 답변(보관되지 않은 내 스크립트, 지금 등급의 AI 답변)의 것만 (`pickDue`). 오래 밀린 것 먼저.
- `/recall`: 한 번에 최대 20문장 (`RECALL_SESSION`). 남으면 요약 화면에서 "이어서 더 복습".
- 한글 뜻만 보여 주고 영어는 가리며 소리도 들려주지 않는다. 결과는 기억함(다음 복습일) / 못 기억함(빠진 단어 표시, 외움 표시 풀림).
- 요약: 기억한 수, 다시 외울 문장 목록. 누르면 그 문장부터 외우기 연습(`/practice/<주제>?v=<답변>&start=<문장>`).

## ① 답변 전체 이어 말하기

### 데이터 (`supabase/migrations/0012_recitations.sql`)

`recitations`: 한 번 이어 말할 때마다 한 줄 (사용자, 주제, 답변 세트, 일치도, 걸린 시간, 문장 수, 막힌 문장 위치, 받아 적은 글).
RLS로 내 답변으로만 남기고 내 것만 본다. 고치거나 지울 수 없다. 테스트: `supabase/tests/07_recitations.sql`.

### 채점 (`lib/recite.ts`, AI 없음 · 사용량 차감 없음)

- 답변 전체를 한 번에 단어 비교한 뒤(문장 경계를 넘어 말해도 맞게 정렬), 모범 단어를 문장별로 다시 나눠 문장마다 맞힌 비율을 낸다.
- 전체 일치도 = 단어 비교 점수 (더 말한 단어도 깎는다). 막힌 문장 = 그 문장 맞힌 비율 80% 미만.
- 외움 표시는 바꾸지 않는다 (확정 2). 학습 기록은 연습 1회로 올린다.

### 화면

- 주제 화면: 모든 문장을 외운 답변이면 큰 버튼이 "답변 전체 이어 말하기", 원래 "처음부터 복습하기"는 아래 글자 버튼("문장별로 처음부터 복습하기"). 마지막 기록이 있으면 "지난 이어 말하기 87%".
- `/recite/<주제>?v=<답변>`: 다 외운 답변만 (아니면 주제 화면으로). 질문을 한 번 들려주고 답변은 모두 가린다.
- 말하는 동안: 시간, 받아 적는 글. 문장 사이 침묵으로 음성 인식이 끝나면 조용히 다시 듣는다 (`listen({ quiet: true })`). "다 말했어요"를 누르거나 3분이 되면 끝.
- 결과: 일치도 · 걸린 시간 · 막힌 문장 수, 지난번과 비교, 목표 시간(1분 30초~2분 30초) 안인지. 막힌 문장은 빠진 단어를 칠해 보여 준다.
- "막힌 문장 N개만 다시 연습" → `/practice/<주제>?v=<답변>&only=2,5` (그 문장들만 지금의 문장 연습으로).

## ③ 실전 모의고사

### 데이터 (`0013_mock_exams.sql`, `0014_mock_used_private.sql`)

- `profiles.mock_monthly_limit` (기본 3, 0~30): 하루 사용량과 따로 세는 한 달 횟수. 운영자 회원 화면에서 바꾼다 (`admin_set_mock_limit`, 기록은 `mock_limit_changes`).
- `mock_exams`: 설문 답, 자가 평가, 문항(1~7번 + 8~15번 세 벌), 고른 난이도, 답(받아 적은 글 · 말한 시간 · 다시 듣기 수), 리포트. 서버(service_role)만 쓰고 본인은 읽기만.
- `finish_mock_exam`: 15번을 마치는 순간(또는 40분이 지나 마칠 때) 1회 센다. 같은 시험은 두 번 세지 않고, 동시에 마쳐도 한도를 넘지 않는다(프로필 행 잠금). 한국 시간 매달 1일에 다시 채워진다.
- 끝내지 않은 시험(active)은 세지 않고 이어 보지도 않는다 (확정 3). 시작 1분 뒤 다시 열면 "이어서 볼 수 없어요".
- 테스트: `supabase/tests/08_mock_exams.sql`.

### 문항 은행 (`lib/mockBank.ts`, 앱 안에 둠)

- 실제 시험의 형식만 따르고 문구는 새로 썼다. 순서: 1 자기소개 · 2~4 설문 활동 A · 5~7 사는 곳 · 8~10 설문 활동 B · 11~13 롤플레이(묻기 → 문제 해결 → 관련 경험) · 14~15 돌발.
- 배경 설문 활동 25개는 앱의 오픽 주제와 같은 id라, 리포트에서 "이 주제 외우기 연습으로" 바로 간다. 실제처럼 12개 이상 고른다.
- 설문 활동 질문은 활동 이름을 넣는 질문 틀 5가지(묘사 · 함께하는 사람 · 습관 · 경험 · 비교), 사는 곳 · 돌발(8개 주제) · 롤플레이(6세트)는 직접 썼다.
- 난이도: 자가 평가 1~2 쉬움, 3~4 중간, 5~6 어려움. 어려울수록 경험 · 비교 · 사회 이슈 질문. 7번 뒤 고른 값(쉽게 / 비슷하게 / 어렵게)으로 8~15번이 한 단계 바뀐다.

### 진행 (`app/mock/[id]/MockExam.tsx`)

- 질문은 소리로만 (TTS), 끝나면 바로 받아 적기 시작. 문장 사이 침묵으로 인식이 끊겨도 조용히 다시 이어 듣는다 (`lib/useLongListen.ts`).
- 문항마다 다시 듣기 1번, 전체 40분(지나면 지금 문항까지 저장하고 마침). 시험 중에는 점수 · 받아 적은 글을 보여 주지 않는다.

### 리포트 (`lib/mockReport.ts`)

- 마친 뒤 응답을 보내고 나서 Sonnet(`claude-sonnet-5-5`, 바꾸려면 `CLAUDE_MOCK_MODEL`)을 한 번 부른다. 구조화된 출력으로 예상 등급 · 위아래 한 칸 범위 · 4개 영역 점수 · 다음에 연습할 것 · 문항별(잘한 점 · 고칠 점 · 고친 예문).
- 비용은 운영자 비용 화면에 "모의고사 리포트"로 따로 잡힌다. 1회 약 100~200원 (가정, 실제 기록으로 확인).
- 화면은 4초마다 다시 읽으며 기다린다. 실패했거나 3분이 넘으면 "다시 만들기" (추가 차감 없음).
- 받아 적은 글자만 본 예상이라는 한계를 리포트에 적는다.
