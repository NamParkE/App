## 0. 화면 원칙: 화면마다 큰 버튼 하나

유저 테스트에서 "한 화면에 여러 갈래의 조작이 있어 뭘 눌러야 할지 모르는" 경험이 나왔다. 이번 기능은 아래 원칙으로 만든다.

- 화면마다 **눈에 띄는 버튼(파란 큰 버튼)은 하나**다. 다른 길은 작은 글자 링크나 뒤로 가기로만 둔다.
- 고를 게 여러 개면 **한 번에 하나씩** 묻는다. 수정안은 목록에서 한꺼번에 고르지 않고, 고칠 문장만 한 장씩 넘기며 고른다.
- 화면 안의 작은 설정(발음 · 번역 보기 체크, 속도 조절)은 주제 화면에서 빼고 연습 화면에만 둔다. 문장 듣기는 문장 줄 자체를 누르면 된다 (따로 있던 스피커 버튼을 없앰).

## 1. 흐름

1. **오픽 시작 (설정):** 오픽 암기형을 고른 다음 "답변은 어떻게 준비할까요?"에서 **AI가 답변 만들기 / 내 스크립트로 연습** 중 하나를 고른다. 버튼은 "다음" 하나. 내 정보 → 바꾸기에서 언제든 바꾼다.
2. **주제 (스크립트 없음):** 기본 방식이 "내 스크립트"면 질문 아래에 큰 버튼 **"내 스크립트 넣기"** 하나. 그 아래 작은 링크 "스크립트가 없어요 · AI 답변으로 연습하기". 기본 방식이 "AI"면 지금처럼 "핵심 답변 만들기"가 큰 버튼이고, 작은 링크가 "내 스크립트 넣기"다.
3. **붙여 넣기:** 입력 칸 하나와 큰 버튼 **"문장 확인하기"**. 문장 수를 바로 보여 주고, 버튼 위에 "확인할 때 연습 1회 차감 · 오늘 N회 남음".
4. **문장 확인 (한 장씩):** "6문장 중 3문장은 그대로 좋아요. 나머지 3문장만 하나씩 볼게요." 고칠 문장만 한 장씩 보여 준다. 카드: 몇 번째 문장, 정도(틀림 / 조금 어색), 내 문장, 수정안, 이유 한 줄, 수정안 듣기.
   - **틀림:** 큰 버튼 "수정안으로 바꾸기", 작은 버튼 "내 문장 그대로"
   - **조금 어색:** 큰 버튼 "내 문장 그대로", 작은 버튼 "수정안으로 바꾸기" (내 익숙한 문장을 지키는 쪽이 기본)
   - 다 고르면 "다 골랐어요" → "다음"
   - 고칠 문장이 하나도 없으면 이 단계를 건너뛰고 5로 간다.
5. **저장 전 확인:** 최종 문장 목록 (고른 수정안은 "수정안" 표시). 큰 버튼 **"저장하고 연습 시작"**. 다시 고르려면 뒤로 가기.
6. **주제 (내 스크립트 + AI 답변):** 둘 다 있을 때만 위에 **"내 스크립트 | AI 답변"** 전환이 생긴다 (하나만 있으면 전환 없음). 문장 줄을 누르면 듣기, 큰 버튼은 "문장 N부터 말하기 연습". 목록 끝에 작은 링크 "스크립트 다시 넣기".

연습 화면(말하기 · 비교 · 코치 한마디)은 지금 그대로 쓴다.

## 2. 데이터

지금의 `answer_sets` / `sentences`를 그대로 쓴다. 연습 · 진도 · 학습 점수 코드를 바꾸지 않기 위해서다.

- `answer_sets.source text not null default 'ai' check (source in ('ai', 'mine'))` 추가
  - `ai`: 지금처럼 등급(`level`)마다 하나
  - `mine`: **주제마다 하나**, 등급과 상관없음 (`level`은 비움). `unique (user_id, topic_id) where source = 'mine'`
  - `level`은 `source = 'ai'`일 때만 필수가 되도록 바꾼다.
- `sentences`에 `edited boolean not null default false` 추가: 수정안으로 바꾼 문장 표시
- `profiles.opic_source text not null default 'ai' check (opic_source in ('ai', 'mine'))`: 기본 방식. 사용자가 고칠 수 있는 칸에 추가
- 홈의 주제별 진도는 기본 방식 쪽 답변의 진도를 보여 준다. 그쪽이 없고 다른 쪽만 있으면 그쪽을 보여 준다.

## 3. 서버 API

| 경로 | 하는 일 | AI | 사용량 |
|---|---|---|---|
| `POST /api/script/check` | 붙여 넣은 글을 문장으로 나누고, 문장마다 판정 · 수정안 · 이유 · 발음 · 번역을 받는다. 저장하지 않는다 | 1회 | 1회 차감 (실패하면 환불) |
| `POST /api/script/save` | 사용자가 고른 최종 문장을 저장한다. 이미 있던 내 스크립트는 바꾼다 | 없음 | 없음 |

- **문장 나누기:** 서버가 문장 끝(`.` `?` `!`) 기준으로 나눈다. 최대 15문장, 2,000자.
- **AI 응답 형식 (구조화 출력):** 문장마다 `verdict`(ok / awkward / wrong), `fix`(ok면 없음), `why`(한국어 한 줄), 원래 문장과 수정안 각각의 `pronunciation`(한글 발음)과 `ko`(번역). 사용자가 어느 쪽을 고르든 발음 · 번역이 있다.
- **안전:** 붙여 넣은 글은 데이터일 뿐 지시가 아니라고 프롬프트에 적는다 (전화영어 모드와 같은 방식).
- **저장 검사:** `save`는 문장 수(1~15)와 길이만 확인한다. (구현하며 바뀜: 처음엔 `check` 결과에 서명을 붙여 확인된 문장만 받으려 했지만, 문장 표는 원래 사용자가 자기 것을 직접 쓸 수 있어(RLS) 서명이 막아 주는 것이 없고, 비용이나 다른 사람에게 영향도 없어 뺐다.)
- **비용 기록:** 운영자 메뉴의 AI 비용에 새 종류 `script`(스크립트 확인)로 쌓는다.
- **스크립트 다시 넣기:** 새로 저장하면 문장이 바뀌므로, 그 주제 내 스크립트의 외움 진도는 처음부터 다시 한다 (AI 답변 진도는 그대로).

## 4. 비용

- 스크립트 확인 1번: 입력 약 1,500토큰, 출력 약 2,500토큰 → Haiku 5.5 기준 약 $0.0014 (2원 안팎)
- 사용량 1회 차감이라 하루 한도 안에서 끝난다.

## 5. 하지 않을 것

- 사진 · PDF 올리기, 문자 인식(OCR)
- 주제와 상관없는 표현 모음
- 스크립트 가족 공유
- 수정안 자동 적용
- 스크립트로 등급 판정

## 6. 정해야 할 것 (승인 때 함께)

1. **"조금 어색"의 기본 버튼:** "내 문장 그대로"를 큰 버튼으로 둔다 (틀림만 수정안을 권함).
2. **주제 화면 정리:** 발음 · 번역 보기 체크와 속도 조절을 주제 화면에서 빼서 연습 화면에만 두고, 문장 줄을 누르면 듣기로 바꾼다. AI 답변 쪽 주제 화면에도 똑같이 적용된다.
3. **스크립트 다시 넣기:** 다시 넣으면 그 스크립트의 외움 진도가 처음부터다.
4. **분량:** 최대 15문장 · 2,000자
5. **차감:** 확인할 때 1회 (저장은 무료). 확인 결과를 저장하지 않고 나가면 그 1회는 돌려주지 않는다.
