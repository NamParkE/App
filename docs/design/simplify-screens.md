# 기존 화면 단순화 설계 (유저 테스트 반영)

- 화면 시안: https://claude.ai/artifact/164n4nSZDJomemPqVFqcaG (화면 6개, 3번 · 4번은 눌러 볼 수 있음)
- 상태: **승인됨 (2026-11-21), 구현 완료.** 결정 6가지는 제안대로 승인됨.
- 배경: 유저 테스트에서 "한 화면에 여러 갈래의 조작이 있어 뭘 눌러야 할지 모르는" 경험이 나왔다. 내 스크립트 화면([`my-script-mode.md`](my-script-mode.md))에 먼저 적용한 원칙을 이전 화면에도 적용한다.

## 원칙

1. 화면마다 **눈에 띄는 큰 버튼은 하나**. 다른 길은 작은 글자 링크나 목록으로 둔다.
2. 자주 안 쓰는 조작(속도, 도움 기능, 설정)은 **한 버튼 뒤의 시트**로 모은다.
3. 고를 수 있는 걸 늘어놓기보다 **앱이 다음 할 일을 정해서** 보여 준다 (이어서 하기, 자동 단계).
4. 내용을 누르면 듣는다: 문장 · 말풍선 · 질문 카드 자체가 듣기 버튼이다 (따로 있던 스피커 버튼을 없앰).

## 화면별 변경

| # | 화면 | 지금 (갈래) | 바꾼 뒤 (큰 버튼) |
|---|---|---|---|
| 1 | 오픽 홈 | 모드 탭 2개, 남은 연습 카드, 분류 칩 3개, 주제 목록, (이어서 하기 카드) | **"오늘 할 것" 카드 하나에 "이어서 연습"**. 이어서 할 게 없으면 다음 주제로 "연습 시작". 그 아래 테두리 버튼 **"다른 주제 고르기"**(아래 주제 목록으로 이동). 남은 횟수는 카드 안 한 줄. 맨 위 **모드 전환 "오픽 암기 \| 전화영어"** (두 모드가 항상 보이고 지금 모드가 칠해짐) |
| 2 | 전화영어 홈 | 모드 탭, 레벨 카드(바꾸기), 이어하기 카드, 오늘의 수업(주제 고르기 + 시작), 표현장 카드, 최근 수업 | **"오늘의 수업" 카드 하나에 "수업 시작"** (끊긴 통화가 있으면 그 자리에 "이어서 통화"가 대신 나옴). 그 아래 테두리 버튼 **"다른 주제 고르기"** → 아래에서 주제 목록 시트가 올라오고, 누르면 오늘의 수업이 바뀜. 레벨 진행은 한 줄로. 복습할 표현 · 최근 수업은 아래 목록. 맨 위 모드 전환은 오픽 홈과 같음 |
| 3 | 말하기 연습 | 다시 듣기, 보면서/가리고 버튼 2개, 속도 버튼 4개, 건너뛰기, 마이크 | **마이크 하나**. "1 보면서 → 2 가리고" 단계가 자동으로 넘어감 (보면서 말하기를 잘하면 다음 시도는 자동으로 가리고). 모범 문장 카드를 누르면 다시 듣기. 속도와 "처음부터 가리고 말하기"는 오른쪽 위 설정 시트로. 건너뛰기는 작은 링크 |
| 4 | 전화영어 통화 | 도움 버튼 4개(다시 듣기 · 천천히 · 힌트 · 한국어로), 말풍선마다 버튼 3개(자막 · 뜻 · 다시 듣기), 마이크 | **마이크 하나** + 작은 "도움" 버튼 → 시트에 다시 듣기 · 천천히 · 대답 예시 · 한국어로 묻기. 말풍선을 누르면 다시 듣기, 말풍선 아래 버튼은 "자막 · 뜻 보기" 하나 (자막과 한글 뜻을 함께 켜고 끔). 끝내기는 위쪽 작은 글자 |
| 5 | 수업 리포트 | "대화 다시 보기"와 "완료"가 같은 크기 | **"완료" 하나**. 대화 다시 보기는 작은 링크 |
| 6 | 내 정보 | 프로필, 사용량, 가족 · 초대 코드, 효과음 설정(스위치 3개), 같은 크기 버튼 3개(표현장 · 비밀번호 · 로그아웃) | 프로필 줄에 사용량을 합침. 표현장 · 가족과 초대 코드 · 소리와 진동 · 비밀번호를 **목록 한 덩어리**로, 각각 누르면 다음 화면. 로그아웃은 맨 아래 작은 글자 |

- 바꾸지 않는 화면: 로그인(이미 큰 버튼 하나), 가족 순위(보기 전용), 표현장(분류 칩만 있음), 내 스크립트 화면(이미 적용), 운영자 메뉴, 어린이 모드 통화(아이용으로 이미 큰 버튼 3개).
- 기능은 빼지 않는다. 자리만 옮긴다 (설정 시트, 도움 시트, 하위 화면).

## 구현 메모

- 연습 자동 단계: 지금의 "외움" 기준(가리고 말하기 90점)은 그대로. 보면서 말하기에서 90점 이상이면 그 문장의 다음 시도를 가리고 말하기로 바꾼다. 설정 시트의 "처음부터 가리고 말하기"를 켜면 1단계를 건너뛴다 (기기에 저장).
- 내 정보의 하위 화면: `/me/family`(가족 · 초대 코드), `/me/sound`(효과음 설정). 지금 내 정보에 있던 내용을 그대로 옮긴다.
- 홈의 "오늘 할 것": 마지막으로 연습한 주제에 외우지 않은 문장이 있으면 그 주제, 아니면 지금 분류에서 처음으로 다 못 외운 주제.

## 정해야 할 것 (승인 때 함께)

1. **모드 전환:** 홈 맨 위에 "오픽 암기 | 전화영어" 두 칸 전환을 둔다 (화면 이동용이라 큰 버튼보다 작고 옅게). 사용자 피드백 반영: 숨은 링크는 직관적이지 않음.
6. **주제 바꾸기:** 큰 버튼 바로 아래 테두리 버튼 "다른 주제 고르기". 전화영어는 시트로 고르고, 오픽은 아래 주제 목록으로 이동. 사용자 피드백 반영: 작은 링크는 찾기 어려움.
2. **연습 자동 단계:** 보면서 말하기를 90점 이상 하면 다음 시도는 자동으로 가리고 말하기.
3. **통화 도움 시트:** 도움 4가지를 시트 하나로 모은다 (누르는 횟수가 한 번 늘어남).
4. **자막 · 뜻 버튼 합치기:** 자막과 한글 뜻을 함께 켜고 끈다.
5. **내 정보 하위 화면:** 가족 · 초대 코드와 소리 설정을 각각 다음 화면으로 옮긴다.
