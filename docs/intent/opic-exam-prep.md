# 오픽 준비 고도화 (외운 문장 복습 · 답변 전체 이어 말하기 · 실전 모의고사): 확정된 의도

- 확정일: 2026-11-21 (interview-me 인터뷰로 사용자 확인 완료)
- 흐름 미리 보기(결정용 스케치): https://claude.ai/artifact/EaGqNrYhT5u4LJjPj9yPt8 (①②③ 판)
- 관련: [`english-opic-app.md`](english-opic-app.md), [`my-script-mode.md`](my-script-mode.md)

## 목표 (Why)

- **결과물:** 오픽 준비 흐름을 완성하는 세 기능.
  - **② 외운 문장 복습:** 외운 문장을 1 · 3 · 7 · 14일 뒤에 다시 물어본다. 한글 뜻만 보고 영어로 말해 90점 이상이면 기억함, 아니면 외움 표시를 푼다. 복습할 날에는 홈 "오늘 할 것" 자리에 "오늘의 복습"이 먼저 나온다. (간격 · 기준은 가정, 설계 때 조정 가능)
  - **① 답변 전체 이어 말하기:** 문장을 다 외운 답변을 처음부터 끝까지 가리고 이어 말한다. 전체 일치도 · 걸린 시간 · 막힌 문장을 보여 주고 "막힌 문장만 다시 연습"으로 이어진다. 채점은 단어 비교(AI 비용 없음).
  - **③ 실전 모의고사:** 실제 오픽과 똑같은 흐름.
    - 시작 전 배경 설문(직업 · 사는 곳 · 취미 등)과 난이도 자가 평가(1~6).
    - 그에 맞춘 15문항: 자기소개 → 설문 주제 묶음 질문 → 돌발 → 롤플레이. 7번 뒤 난이도 재조정.
    - 실제 시험처럼 전체 40분, 질문은 문항마다 한 번 다시 듣기 가능 (가정).
    - 문항 은행은 실제 오픽 형식으로 미리 만들어 앱에 넣어 둔다 (가정).
    - 끝나면 예상 등급 + 문항별 피드백 리포트. 리포트만 Sonnet 으로 만들고, 화면에 "예상"이라고 분명히 적는다.
- **사용자:** 오픽 준비자. 판매할 수 있는 완성도가 목표 (기한 없음).
- **성공 기준:** 외운 답변을 시험 날까지 유지하고, 2분 안팎을 끊김 없이 말하고, 실제와 같은 시험을 미리 겪어 자기 등급을 가늠한다.
- **제약:**
  - 모의고사는 하루 사용량과 따로 세는 전용 횟수 **한 달 3회** (매달 1일, 한국 시간 다시 채움). 운영자 메뉴에서 사람마다 바꿀 수 있다. 끝내지 않고 나가면 차감하지 않는다.
  - 비용: 모의고사 1회 약 100~200원, 월 2만 원 목표 안.
  - 채점은 음성 인식으로 받아 적은 글자만. 발음 · 억양 · 속도는 평가하지 않고, 그 한계를 리포트에 적는다.

## 하지 않을 것 (Out of scope)

- 결제 · 과금 체계 (모의고사 횟수는 그 전까지 임시로 월 3회)
- 소리 자체를 분석하는 발음 평가
- 실제 등급 보장 (예상만)
- 녹음 파일 저장 · 다시 듣기
- 아이용 모의고사
