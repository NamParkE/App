# 운영자 메뉴: 확정된 의도

- 확정일: 2026-11-20 (interview-me 인터뷰로 사용자 확인 완료)

## 목표 (Why)

- **결과물:** 서비스 운영자 전용 "운영자 메뉴"를 앱 안에 만든다. 폰에서 열 수 있고, `owner_emails`에 등록된 계정에만 보인다.
- **사용자:** 서비스 운영자(앱 주인) 한 명. 모든 가족·사용자가 대상이다.
- **왜:** 지금은 한도 변경과 비용 확인을 SQL과 Anthropic 콘솔에서 따로 해야 한다. 서비스를 운영할 때 참고할 데이터를 한곳에서 보려는 것이다.
- **맨 위 숫자 4개:**
  1. 이번 달 AI 비용(원)과 월 2만 원 목표 대비 비율
  2. 오늘 · 이번 주 실제로 학습한 사람 수
  3. 오늘 하루 한도를 다 쓴 사람
  4. 모드별 사용량 (오픽 연습 횟수, 전화영어 수업 횟수)
- **그 아래:** 가족별 · 사람별 목록. 사람을 누르면 하루 한도(`daily_limit`)를 바꿀 수 있다.
- **AI 비용 계산:** 앞으로 AI를 부를 때마다 사용한 토큰 수를 기록해 실제 금액을 계산한다. 기능을 만들기 전의 비용은 나오지 않는다 (그 기간은 Anthropic 콘솔에서 확인).
- **제약:**
  - 숫자만 본다. 이름 · 이메일 · 가족, 횟수, 학습일, 레벨, 비용까지만 보고, 대화 · 문장 · 리포트 내용은 보지 않는다.
  - 운영자만 접근할 수 있게 서버에서 막는다.

## 하지 않을 것 (Out of scope)

- 다른 사용자의 학습 내용(대화, 문장, 리포트) 열람
- 사용자의 학습 기록 수정 · 삭제
- 계정 삭제 · 정지
- 결제, 요금제
- 시간대별 · 화면별 같은 세밀한 분석
- 알림 발송

## 다음 단계
