# 오픽 직접 답변 입력 (내 스크립트): 확정된 의도

- 확정일: 2026-11-21 (interview-me 인터뷰로 사용자 확인 완료)
- 관련: [`english-opic-app.md`](english-opic-app.md) (오픽 암기형)

## 목표 (Why)

- **결과물:** 오픽 암기형에 "직접 답변 입력"을 추가한다. 주제마다 내 스크립트(영어 단락)를 붙여 넣으면 문장 단위로 나눠, 지금처럼 듣기 · 따라 말하기 · 비교로 연습한다.
- **수정안:** 붙여 넣은 뒤 확인 화면에서 문장마다 "괜찮음 / 조금 어색 / 틀림"을 표시하고 수정안을 보여 준다. 사용자가 문장마다 "수정안으로 바꾸기" 또는 "내 문장 그대로"를 고른다. 앱이 마음대로 바꾸지 않는다.
- **방식 선택:** 오픽 모드를 시작할 때 "AI 답변 생성" / "직접 답변 입력" 중 기본 방식을 고르고, 내 정보에서 언제든 바꿀 수 있다. 주제마다 AI 답변과 내 스크립트를 하나만 쓰거나 둘 다 쓸 수 있고, 둘 다 있으면 주제 화면에서 바꿔 가며 연습한다.
- **사용자:** 학원 · 유튜브 등에서 받은 익숙한 스크립트로 연습하려는 오픽 준비자
- **왜:** 익숙한 문장을 지정해서 연습하려는 사용자가 있다. 지금은 AI가 만든 답변으로만 연습할 수 있다.
- **성공 기준:** 내 스크립트를 넣고 몇 분 안에 문장별 연습을 시작하고, 어색한 문장은 내가 고른 만큼만 고쳐진다.
- **제약 (확인된 가정):**
  - 스크립트를 넣고 수정안을 받을 때 사용량 1회 차감 (지금 "답변 만들기"와 같음). 다 맞게 말하면 차감하지 않는 연습 규칙은 그대로.
  - 내 스크립트는 목표 등급과 상관없이 주제마다 하나. 등급을 바꿔도 남는다.
  - 문장 카드의 발음 · 한글 번역은 수정안을 만들 때 AI가 함께 만든다.

## 하지 않을 것 (Out of scope)

- 파일(사진 · PDF) 올리기, 스크립트 문자 인식(OCR). 붙여 넣기만 한다.
- 주제와 상관없는 표현 모음
- 스크립트를 가족과 공유
- 수정안 자동 적용
- 스크립트로 등급 판정
