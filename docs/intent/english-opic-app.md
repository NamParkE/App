# 영어 말하기 학습 앱 (오픽 암기형 우선): 확정된 의도

- 확정일: 2026-11-20 (interview-me 인터뷰로 사용자 확인 완료)

## 목표 (Why)

- **결과물:** 안드로이드 폰에서 링크로 여는 영어 말하기 학습 웹앱(PWA). 첫 버전은 **오픽 암기형** 모드를 완성한다. 오픽 빈출 주제마다 사용자 수준에 맞는 핵심 답변 문장을 만들고, 사용자가 마이크로 반복해 말하며 외운다.
- **대화 방식 (턴 방식):** 마이크 버튼으로 녹음 → 텍스트 변환(STT) → AI 답변 → 음성 재생(TTS). AI 답변은 소리와 텍스트 세 줄(영어 원문 / 영어 발음 / 한글 번역)로 제공한다. 암기형 모드에서는 사용자가 말한 문장과 모범 문장을 비교해 피드백한다.
- **사용자:** 로그인한 가족 구성원. 각자 학습 스타일과 수준(목표 등급, 예: IM2 / IH / AL)을 직접 고른다.
- **왜 지금:** 가족 중 오픽 준비자가 있고, 나중에 판매할 수 있는 수준의 앱으로 키우려 한다.
- **성공 기준:** 가족 각자가 원하는 학습 스타일로 만족하며 학습한다. 첫 기준은 오픽 준비자가 이 앱으로 핵심 답변을 완성도 있게 외워 말할 수 있게 되는 것이다.
- **제약:** 본인 API 키 하나로 비용을 감당한다. 사용자별 하루 사용량을 제한하고, 목표 비용은 월 몇천 원에서 2만 원 수준이다. 판매로 확장할 수 있게 로그인과 사용자 데이터 구조는 처음부터 제대로 만든다.

## 하지 않을 것 (Out of scope)

- 결제 기능
- 아이폰(iOS) 지원, 스토어 앱 출시
- 실시간 음성 대화(말 끊기 포함): 턴 방식만 지원한다.
- 어휘 확장형 모드: 첫 버전에서 제외하고, 스타일 선택 화면에 자리만 둔다.

## UI 디자인 시안 (승인됨)

- 승인일: 2026-11-20
- 시안: https://claude.ai/artifact/8wQAC8nb6oypSCsqD8AccE
- 화면 6개 (폰 390×844):
  1. 로그인: Google / 이메일 로그인, 가족 초대 코드
  2. 목표 등급 · 학습 스타일: IM2 / IH / AL, 오픽 암기형 (어휘 확장형은 "준비 중" 자리만)
  3. 홈: 오늘 남은 연습 횟수, 이어서 하기, 빈출 주제별 진도 (설문 / 돌발 / 롤플레이)
  4. 주제 · 핵심 답변: 질문, 문장 카드 (영어 원문 / 영어 발음 / 한글 번역), 외움 상태, 듣기
  5. 말하기 연습: 마이크 턴 (대기 / 녹음 중 / 분석 중), 보면서 말하기 / 가리고 말하기
  6. 비교 피드백: 일치도, 단어 단위 비교 (빠뜨림 / 바꿔 말함), 코치 한마디, 다시 말하기 / 다음 문장
- 시안에서 정한 가정 (구현 때 조정 가능): 하루 30회 표시, 등급별 답변 길이 IM2 4~5문장 / IH 6~8문장 / AL 8문장 이상, "기록" 탭은 자리만 둠.
