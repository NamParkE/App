# 어휘 확장형 (전화영어 모드): 확정된 의도

- 확정일: 2026-11-20 (interview-me 인터뷰로 사용자 확인 완료)
- 관련: [`english-opic-app.md`](english-opic-app.md) (첫 버전에서 이 모드는 스타일 선택 화면에 "준비 중" 자리만 둠)

## 목표 (Why)

- **결과물:** AI 선생님과 **버튼 방식**으로 영어 대화 수업을 하는 새 학습 모드(스타일 선택 화면의 "어휘 확장형")를 만든다.
  - 레벨은 **아이 수준부터 원어민 수준까지** 여러 단계다.
  - 그날의 주제로 10분 정도 듣고 말한다.
  - 수업이 끝나면 고칠 점과 새 표현을 정리해 준다.
  - 전화영어처럼 듣기와 말하기를 함께 훈련한다.
- **사용자:** 오픽을 준비하지 않는 가족 구성원. 영어 초보부터 상급자까지. 화면은 지금 앱 스타일을 쓴다.
- **왜 지금:** 오픽 암기형 첫 버전이 완성·배포됐고, 처음 목표인 "가족 각자 원하는 학습 스타일로 학습"을 채우기 위해서다.
- **성공 기준:**
  - 가족이 스스로 꾸준히 수업을 하고, **레벨이 올라가는 것**이 눈에 보인다.
  - **연속 학습일**을 보여 주고, 연속 일수에 따라 **시각 효과**(예: 불꽃이 커지거나 배지)가 달라진다.
  - **같은 가족 계정 안에서** 이번 주 학습량(수업 횟수, 연속 일수 등)을 **비교**할 수 있다. 이 비교에는 오픽 암기형 학습도 포함한다.
- **제약:**
  - 지금과 같은 API 키 하나로 비용을 감당한다 (기본 모델 Haiku, 월 2만 원 이내 목표).
  - AI 호출은 사용자별 하루 사용량 한도에 포함된다.
  - 버튼을 눌러 번갈아 말하는 턴 방식만 지원한다.
  - 안드로이드 폰(웹앱 / APK) 기준이다.

## 하지 않을 것 (Out of scope)

- 실시간 음성 대화 (버튼 없이 계속 듣기, 말 끊기)
- 어린아이 전용 화면 (그림 위주 UI 등)
- 사람 선생님 연결
- 결제, 아이폰(iOS)
- 가족 밖 사람과의 순위·비교

## 다음 단계

- 구현 전에 **설계**(수업 흐름, 레벨 체계와 레벨 업 기준, 연속 학습일·시각 효과, 가족 비교 화면, 데이터 구조, 비용 추정)를 먼저 만들어 사용자 확인을 받는다.
- 설계에는 화면 시안도 포함한다. 첫 버전처럼 승인 전에는 구현하지 않는다.
